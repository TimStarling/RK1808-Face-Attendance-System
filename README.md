# RK1808-Face-Attendance-System
武汉纺织大学课程设计，RK1808智能人脸考勤系统是一款基于Linux嵌入式平台开发的考勤管理系统，以RK1808开发板为核心，结合V4L2视频采集、RockX人脸识别算法、DRM图形显示框架及TCP/IP网络通信技术，实现人脸录入、身份识别、考勤打卡、记录管理和管理员后台等功能。系统通过摄像头实时采集人脸图像，完成目标检测、特征提取与身份匹配，并自动保存考勤记录。管理员可对人脸库和考勤数据进行查询、删除及补卡管理。项目采用模块化设计，涵盖嵌入式Linux开发、图像处理、多线程编程和网络通信等关键技术，具有良好的实用性、扩展性和工程实践价值。
